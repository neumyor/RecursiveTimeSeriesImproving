# Listening to the Residuals: 用残差最优性证书引导 LLM 发现时序预测结构

> Mini-paper 草稿 v0.1（2026-10-15）。目标：KDD / ICML / NeurIPS 2027。
> 本文档只讲清科研叙事与方法设计，不涉及系统工程细节。

---

## 摘要

LLM agent 已经可以自主编写、训练和迭代时序预测模型，但现有方法几乎都用一个标量指标（MSE/MAE）驱动搜索。我们认为，这是 agent 在时序结构设计上难以突破固有认知的主要原因：标量只说明“差多少”，不说明“缺了什么”。agent 只能退回到文献先验里去猜，而时序文献的实证结论本身噪声很大，这种先验尤其不可靠。

我们注意到，时序预测有一个其他 ML 领域没有的性质：**最优预测器的残差必须是不可预测的新息（innovation）**。因此，任何模型的残差都同时给出三样东西：一张**最优性证书**（残差是否已经白化），一个**剩余提升空间的可计算下界**（Kolmogorov–Szegő 公式），以及一个**可以直接对应到结构机制的缺陷坐标**（频率、滞后、预测步长、通道）。

基于这一点，我们提出 **RESIDUAL**：一个只有三步的 agent 循环。

1. **诊断**：把残差可预测性分解为一张带坐标的“缺陷卡”。
2. **定位**：用逐层线性探针判断缺失的信号在网络哪一层丢失。
3. **修复**：agent 针对缺陷修改结构。只有指标提升、并且它声称要修的缺陷确实缩小时，修改才被接受。

当证书显示剩余可预测性与零无显著差异时，循环以“已认证饱和”终止。

我们在**最优预测器解析已知**的合成过程上，直接测量 agent 离理论最优的距离；在真实 benchmark 上，用“已知设计空间之外的结构”定量衡量创新性，不依赖 LLM 打分。

## 1. 引言

### 1.1 现象：agent 会设计模型，但不会“发明”模型

近两年，LLM 驱动的模型与程序自动发现进展很快：AlphaEvolve / ShinkaEvolve 在算法发现上超过了人类最优解，ASI-Arch 自主发现了一百多种线性注意力结构，SEATS 把代码演化用到了时序预测上。但大量证据表明，LLM 生成的方案会趋同：

- Si et al.（ICLR 2025）发现，即使明确要求不重复，LLM 的想法仍会大量重复，扩大采样规模也换不来多样性。
- 2602.20408 把原因归为两点：**个体固着**（早期输出约束后续输出），以及**知识聚合**（预训练把所有知识压进同一个先验）。
- 在时序场景里，表现就是 agent 反复在 patching、RevIN、分解、换序列层这几种做法之间来回组合。

### 1.2 诊断：问题出在反馈信号，而不只是 LLM

我们的核心论点：**固着不只是 LLM 的问题，也是反馈信号的问题。**

现有的时序 agent，无论是 AIDE 式迭代、MCTS 还是演化搜索，从环境得到的信息几乎都只有一个验证集分数。标量反馈有两个缺陷：

1. **没有方向**。分数不会告诉 agent 缺的是周期成分、高频成分，还是长步长上的衰减。agent 只能依据“文献里什么有效”去猜。
2. **无法分辨“到顶了”还是“卡住了”**。agent 不知道当前模型离最优还有多远，也就没有理由放弃熟悉的路线、去尝试陌生的。

在时序领域，第 1 点尤其致命：ICML 2026 的 position paper（2512.22702）指出，被当作“实现细节”的设计维度对结果的影响常常超过换一种序列层，TimeRecipe（ICLR 2026）也发现，单靠模块重组就能在 92/102 个场景中超过 SOTA。也就是说，**LLM 从时序文献中学到的“什么结构有效”本身就是一个高噪声先验**。只用标量反馈、又依赖这个先验的 agent，自然会收敛到重组和调参。

### 1.3 思路：让数据而不是文献告诉 agent 缺什么

时序统计学 50 年前就有答案：Box–Jenkins 方法论的核心循环是 **识别 → 估计 → 残差诊断 → 再识别**，靠残差的自相关和谱结构来告诉建模者还缺什么。我们把这一循环推广到深度结构搜索：把残差诊断变成 agent 的主要反馈，让 agent 推理的锚点从“最近流行什么模型”变成“数据里还有什么信号没被模型吃掉”。

### 1.4 贡献

1. **问题刻画**：指出标量反馈加高噪声文献先验，是 LLM 在时序结构发现中固着的原因，并给出可测量的固着指标。
2. **残差证书**：一个与模型无关、可以按坐标分解的剩余提升空间下界，包括线性部分（Kolmogorov–Szegő）、非线性部分（探针下界），以及对应的“已认证饱和”停止准则。
3. **RESIDUAL 循环**：诊断、定位、修复三步，加上“机制一致”接受规则。不依赖种群、岛屿或 LLM 评委。
4. **评测协议**：最优解已知的合成过程组，以及以已知设计空间为参照、可以客观计算的创新性指标。

## 2. 为什么只有时序可以：三个性质

这一节是论文的立足点。我们论证 RESIDUAL 依赖时序预测的三个性质，而它们在其他主流 ML 领域目前不同时成立。

### P1：最优性可检验，且不需要知道最优模型长什么样

由 Wold 分解，对平稳过程 $\{x_t\}$，基于全部过去信息 $\mathcal{F}_{t-1}$ 的最优一步预测残差

$$e_t^\star = x_t - \mathbb{E}[x_t \mid \mathcal{F}_{t-1}]$$

是鞅差序列：它与任何过去可观测的量都不相关；在线性情形下就是白噪声。所以对任意模型 $m$，**只要其残差 $r_t$ 能被过去预测，$m$ 就一定不是最优的**。这个检验不需要知道真实模型，也不需要知道最优误差是多少。

**对比**：图像分类中，贝叶斯最优分类器的错误样本没有已知的统计结构，单看错误本身无法判断分类器是否已经最优；语言模型的困惑度没有可以计算的下界。

### P2：缺陷落在可以直接对应到结构的坐标系里

时序残差的可预测性可以沿四个坐标分解，每个坐标都直接对应一类结构机制：

| 残差坐标 | 典型缺陷 | 对应的结构机制 |
|---|---|---|
| 频率 $\omega$ | 周期 24 处谱峰残留，高频能量欠拟合 | 季节/频域模块、滤波器组、频谱偏置 |
| 滞后 $k$ | 长滞后自相关残留 | 感受野、lookback 长度、记忆机制 |
| 预测步长 $h$ | 误差随步长的增长快于理论速度 | 解码器、自回归还是直接预测、多步一致性 |
| 通道 $(i,j)$ | 通道 $i$ 的残差与通道 $j$ 的过去相干 | 通道独立还是混合、跨变量注意力 |

**对比**：NLP 的错误是语义层面的（如“多跳推理失败”），对应不到具体结构组件；表格数据是 iid，残差没有可以利用的顺序结构；CV 的错误可以按类别或属性切片，但这些切片没有“剩余可预测性”的含义。

### P3：剩余提升空间可以计算

Kolmogorov–Szegő 公式给出了平稳过程一步最优线性预测误差：

$$\sigma^2_{\mathrm{KS}} = \exp\!\left(\frac{1}{2\pi}\int_{-\pi}^{\pi} \log f(\omega)\, d\omega\right)$$

其中 $f(\omega)=\sum_h \gamma(h)e^{-ih\omega}$。把它用到**模型残差**上，就得到一个可计算的剩余提升空间（第 3.1 节）。agent 由此可以区分“还有 38% 的可预测方差没吃掉”和“已经到噪声底了”。

**对比**：除时序外，只有已知控制方程的物理问题（如 PDE 残差）才有类似证书，但那要求已知方程；我们的证书**不需要方程，也不需要模型假设**。

### 附加条件：可以造出最优预测器已知的任务

AR/ARMA、多周期季节过程、耦合振子等合成过程的最优预测器和最优误差都可以解析得到。这让我们能**直接测量 agent 离理论最优还有多远**，而 CV/NLP 无法构造“最优分类器已知”的非平凡任务。

> **小结**：P1 告诉 agent“还没完”，P2 告诉 agent“缺什么、改哪里”，P3 告诉 agent“还剩多少”。
> 标量 MSE 三者都给不了，其他领域目前也无法同时给出这三者。

## 3. 方法：RESIDUAL

```
         ┌────────────────────────────────────────────────────────┐
         ▼                                                        │
  ① 诊断 Diagnose            ② 定位 Localize          ③ 修复 Repair
  残差证书 → 缺陷卡           逐层探针 → 丢失位置       agent 改结构
  (缺什么、剩多少)            (在哪一层丢的)            机制一致才接受 ──┘
         │
         └── 剩余提升空间 ≈ 0 → 已认证饱和，停止
```

**数据切分**：train / diag / test。所有诊断和接受判定都只用 diag；diag 内部再按时间切成两半，探针在前一半上拟合、后一半上评估；test 只在最后评测一次。

### 3.1 诊断：残差证书与缺陷卡

对当前模型 $m$，在 diag 上做滚动起点预测，得到步长 $h$ 的残差序列 $r^{(h)}_t$。

**(a) 线性剩余提升空间（$h=1$）。** 设残差均值为 $\mu$、方差为 $\sigma_r^2$、谱密度为 $f_r$，定义

$$H_{\mathrm{lin}} = \mu^2 + \sigma_r^2 - \sigma^2_{\mathrm{KS}}(r)$$

因为 $r_{t-k}$ 都是 $\mathcal{F}_{t-1}$ 可测的，用残差自身的过去去预测 $r_t$ 得到的修正量，加回原预测上，就是一个合法的、更好的预测器。所以 $H_{\mathrm{lin}}$ 是 $m$ 的 MSE **可降低量的下界**，当且仅当残差为零均值白噪声时等于 0。它与信号处理中的谱平坦度（spectral flatness）直接相关：$\sigma^2_{\mathrm{KS}}/\sigma_r^2 = \mathrm{SFM}(f_r)$。

**按频段的精确分解。** 由 $\sigma_r^2=\frac{1}{2\pi}\int f_r$，可得

$$H_{\mathrm{lin}} - \mu^2 = \frac{1}{2\pi}\int_{-\pi}^{\pi}\big(f_r(\omega)-\sigma^2_{\mathrm{KS}}\big)\,d\omega = \sum_b H_b$$

$H_b$ 就是频段 $b$ 对剩余提升空间的贡献。这个分解是精确的，不是启发式。由于 $\sigma^2_{\mathrm{KS}}$ 是谱的几何均值，谱低于几何均值的频段 $H_b<0$，它们代表“已被过度压低”的频段，缺陷卡只把正贡献频段列为缺陷。估计时用对数周期图，并做偏差修正：$\hat\sigma^2_{\mathrm{KS}} = \exp(\overline{\log I(\omega_j)} + \gamma)$，其中 $\gamma$ 是 Euler 常数。

**(b) 非线性 / 多步 / 跨通道剩余提升空间。** 用一个小的残差探针 $g$（线性模型或两层 MLP），只输入在预测时刻已经可得的信息：步长 $h$ 时只用滞后 $\ge h$ 的残差，加上原始过去值和其他通道的过去值。

$$H_{\mathrm{nl}}^{(h)} = \mathrm{MSE}_{m}^{(h)} - \mathrm{MSE}_{m+g}^{(h)}$$

在 diag 后半段上评估，这同样是一个可实现的提升下界。分别遮蔽探针的输入组（滞后段、通道），就得到按滞后和按通道的分解。

**(c) 缺陷卡。** 把上面的结果按贡献从大到小排序，得到一张结构化、带置信区间的卡片：

```
DEFECT CARD  model=cand-07  MSE=0.412  headroom(lin)=0.071 [0.058, 0.083]  (17% of MSE)
  #1  frequency band ω≈2π/24       H_b = 0.039 (55%)  集中在 ch3, ch7
  #2  horizon h>48                  H_nl 增长 2.1× (理论 1.3×)
  #3  cross-channel ch5←ch2 lag 3   H = 0.009 (13%)
  saturation test: REJECT (p<0.001)
```

**领域知识只在这里起作用**：它决定分析残差时用哪套频段和通道分组。例如电力负荷用日、周、年周期频段，ECG 用 RR 节律和 QRS 频段，交通用早晚高峰。agent 根据领域资料生成这些坐标定义，每个定义都要先在注入了已知成分的合成残差上自检，能正确检出、不误报，才可以使用。

### 3.2 定位：缺失信号在哪一层丢失

对缺陷卡上排名第一的缺陷（例如频段 $b$），构造**目标信号** $s_t$：未来窗口真值在频段 $b$ 上的带通分量。然后在模型每一层的表示 $z^{(\ell)}$ 上训练一个线性探针 $s_t \approx W_\ell z^{(\ell)}$，得到**可解码曲线** $R^2(\ell)$，并与两个参照比较：原始 lookback 输入上的可解码性 $R^2_{\text{in}}$，以及模型输出中保留的比例 $R^2_{\text{out}}$。

| 曲线形态 | 结论 | 典型修改方向 |
|---|---|---|
| $R^2_{\text{in}}$ 高、第 1 层就骤降 | embedding 或 patching 破坏了该成分 | 输入表示（如相位保持、分频段 embedding） |
| 中间层高、$R^2_{\text{out}}$ 低 | 信息在内部，但解码不出来 | 投影头、解码器 |
| 逐层缓慢衰减 | 深度方向逐渐遗忘 | 残差通路、跨层连接 |
| $R^2_{\text{in}}$ 本身就低 | lookback 里没有这个信息 | 加长 lookback、引入外生变量 |

这一步把“缺什么”变成“改哪里”，是把结构修改从猜测变成推理的关键。

### 3.3 修复：机制一致接受

agent（任意代码 LLM）拿到父模型代码、缺陷卡和定位结论，必须先**写出可证伪的预期**，再提交修改：

> “目标缺陷 #1。机制假设：patch 内的线性投影把周期 24 的相位混掉了。修改：……。预期：$H_{b=24}$ 下降至少 50%，第 1 层的 $R^2$ 恢复到 0.6 以上。”

候选 $c'$ 替换父模型 $c$，需要同时满足：

1. **有效**：diag 上的 MSE 显著下降（按窗口做配对检验，并与重复种子带来的噪声比较）；
2. **机制一致**：被声称的目标缺陷确实缩小，$H_{\text{target}}(c') < H_{\text{target}}(c)$，并且超过估计误差。

MSE 下降但目标缺陷没有缩小的候选记为 **off-target**，不接受，但会记录下来，作为固着分析的数据。

**停止**：当 $H_{\mathrm{lin}}$ 和各步长的 $H_{\mathrm{nl}}$ 都不显著大于 0 时，判定为**已认证饱和**，输出最终模型。这是一个有理论依据的停止准则，而不是简单设一个候选数上限。

### 3.4 方法刻意不包含的东西

为了让贡献清楚可归因，RESIDUAL **不使用**种群或岛屿、MAP-Elites、persona、LLM 评委、文献检索增强。它是一个单父代的贪心循环，唯一的变量是反馈信号。这样，实验中观察到的所有差异都可以归因于残差证书本身。

## 4. 实验设计

### 4.1 研究假设

- **H1（逼近最优）**：在候选数相同的条件下，RESIDUAL 比标量反馈更接近理论最优误差。
- **H2（不是信息量的问题）**：与“信息量相同、但没有最优性含义”的通用错误分析反馈相比，RESIDUAL 仍有显著优势。
- **H3（打破固着）**：RESIDUAL 产生的结构修改中，落在已知设计空间之外的比例显著更高。
- **H4（机制可信）**：RESIDUAL 接受的修改中，预期机制得到验证的比例显著更高，并且这一比例与最终 test 上的增益正相关。

### 4.2 任务

**合成过程（最优已知）**

| 过程 | 考察的能力 | 最优误差 |
|---|---|---|
| 高阶 AR / ARMA | 长滞后依赖 | 新息方差，解析已知 |
| 多周期季节过程（24 与 168） | 多尺度周期 | 解析已知 |
| 频率漂移正弦加噪声 | 非平稳周期 | 已知状态下可数值计算 |
| 带滞后耦合的振子网络 | 跨通道滞后依赖 | 解析或数值已知 |
| Lorenz-63 加观测噪声 | 非线性动力学 | 短步长下趋近观测噪声底 |

主要指标：**最优性差距** $(\mathrm{MSE}-\sigma^{2\star})/\sigma^{2\star}$ 随候选数的变化曲线。

**真实数据**：ETTh1/ETTm1、Weather、Electricity、Traffic，以及 GIFT-Eval 或 fev-bench 的一个子集。所有候选在 lookback、归一化和调参预算上保持一致，test 只评测一次。

### 4.3 对比方法（相同 LLM，相同候选数）

1. **Scalar**：只给验证集 MSE 和修改历史（AIDE 式）。
2. **Scalar+ErrorAnalysis**：附加通用错误分析，如最差窗口、按数据集切片的误差，**文本长度与缺陷卡相当**。这是检验 H2 的关键对照。
3. **SEATS 式**：MCTS 加全局最好和最差解对比（可复现的部分）。
4. **TimeRecipe 搜索**：在已知模块空间里做随机搜索或贝叶斯优化，作为“只靠重组能达到的上限”。
5. **人工 SOTA**：DLinear、PatchTST、iTransformer、TimeMixer。

### 4.4 固着与创新性的度量（不依赖 LLM 评委）

- **设计空间外比例**：把每个被接受的修改映射到 TimeRecipe 的五组件规范架构中，能被现有模块组合表达的算作“空间内”，否则算作“空间外”。由两名作者独立标注，并报告一致性。
- **机制一致率**：被接受的修改中，事先声称的探针变化确实发生的比例。
- **off-target 率**：MSE 提升但目标缺陷未缩小的候选比例，作为“伪改进”的度量。

### 4.5 消融

| 变体 | 回答的问题 |
|---|---|
| 只做诊断（去掉定位） | 定位层探针的作用 |
| 去掉剩余提升空间数值，只保留缺陷坐标 | P3 的作用 |
| 去掉机制一致接受，只按 MSE 接受 | 接受规则的作用 |
| 用通用频段替代领域坐标 | 领域知识的作用 |
| 换用不同的 LLM | 结论是否依赖特定 LLM |

## 5. 相关工作定位

- **LLM 驱动的程序与结构演化**：FunSearch、AlphaEvolve、ShinkaEvolve、LEVI、LLMatic、EvoPrompting、ASI-Arch。它们改进的是**搜索策略**（档案库、多样性、采样），反馈仍是标量适应度。我们改进的是**反馈信号本身**，二者正交，可以组合。
- **结构化反馈引导演化**：Little Scientist（逐实例诊断）、Component-Aware Feedback、Self-EvolveRec、EvoEngineer、OPERA（把只给分数换成给残差向量后，“分数涨但物理没改进”的比例从 39.5% 降到 2.3%）。这些工作证明了结构化反馈普遍有效，但诊断都是**手工启发式**，没有最优性含义。我们的诊断来自时序预测的最优性理论，并且附带剩余提升空间。
- **时序 agent**：TimeSeriesScientist、TS-Agent、TimeCopilot 做模型选择和流程自动化；SEATS 做代码演化。SEATS 是最直接的对比对象，它的反馈是标量指标驱动的 MCTS。
- **时序模型可解释性**：Wiliński et al. 的逐层探针与 steering、TSFM 内部语义、PatchTST 上的 SAE、频谱偏置研究（FreIE、Fredformer）。这些工作用来**解释**模型，我们把类似工具变成**结构搜索的反馈**。
- **经典时序诊断**：Box–Jenkins、Ljung–Box、累积周期图检验、Kolmogorov–Szegő。我们的定位是：把经典诊断首次用作 LLM 结构发现的引导信号，并扩展到深度模型的逐层定位。

## 6. 预期质疑与回应

| 质疑 | 回应 |
|---|---|
| “这不就是 Ljung–Box 吗？” | 是有意为之：贡献不在发明新的检验，而在指出它能解决 LLM 结构发现中的固着问题，并把它扩展成可分解的剩余提升空间、逐层定位和机制一致接受。 |
| 多步预测的最优残差不是白噪声 | 正确。步长 $h$ 的最优残差是 MA($h-1$)。所以 $H_{\mathrm{nl}}^{(h)}$ 的探针只使用滞后 $\ge h$ 的残差，零假设在构造上就是正确的。 |
| 真实数据非平稳，KS 公式不成立 | KS 只作为一步线性部分的估计，在滚动窗口内计算；主证据依赖探针下界 $H_{\mathrm{nl}}$，它不需要平稳性假设，只依赖时间切分的 held-out 评估。 |
| agent 会不会对诊断过拟合 | 诊断与接受只用 diag，test 只评测一次；我们会报告 diag 与 test 增益的相关性。 |
| 算力 | 候选控制在 DLinear 到 PatchTST 的规模，单个训练几分钟；所有对比在相同候选数下进行。合成任务的成本更低。 |

## 7. 最小验证实验（先做这个）

**目的**：在投入工程之前验证核心主张。

- **设置**：3 个合成过程（高阶 AR、多周期季节、耦合振子）加 ETTh1；Scalar 和 RESIDUAL-lite（只做诊断与接受规则，不做定位）两组；每组 30 个候选，3 个种子。
- **成功信号**：
  1. 在合成任务上，RESIDUAL-lite 的最优性差距曲线明显低于 Scalar；
  2. 两者被接受的修改类型分布有可见差异；
  3. 缺陷卡上的头号缺陷在被接受的修改后确实缩小。
- **如果失败**：信号 1 不成立，说明 LLM 无法利用结构化反馈，需要先改进缺陷卡的表述；信号 1 成立但信号 2 不成立，也可以接受：只要修改是由缺陷卡正确引导的，即使是经典修法，论文主张仍然成立。
